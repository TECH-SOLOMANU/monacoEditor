01 · The Story

Why does this repository exist?

The easiest way to understand the project is to follow its evolution. It started with Monaco as a browser editor and progressively added the tools developers need around the editing experience.

The central idea

A code editor is only the center of a developer workflow. Once the developer starts typing, the application also needs to understand the source, identify problems, explain those problems, inspect the syntax tree, manage files and show the result.

This repository connects those responsibilities around the Monaco Editor engine. Babel provides JavaScript parsing and AST information, while the application converts parser results into Monaco markers, error panels and inspection tools.

Simple mental model:
Monaco edits the code. Babel understands the code. The application connects the two.

02 · Capabilities

What can the workspace do?

The current architecture goes beyond displaying a textarea. It creates a feedback loop between source code, diagnostics and developer actions.

⌨

Monaco Editing

VS Code's browser editing engine provides syntax highlighting, cursor management, models and editor behavior.

!

Live Diagnostics

Babel parse errors are converted into Monaco model markers and shown as red squiggly underlines.

?

Hover Errors

Move over a marked location to read the parser error message and understand where the problem occurred.

◇

AST Inspector

Inspect the live Babel AST structure and understand how source code becomes a tree of syntax nodes.

↳

Error Console

Errors can be collected in a panel and clicked to reveal the corresponding line directly in the editor.

◫

Live Preview

Advanced versions introduce a split preview workflow so source editing and rendered output can be viewed together.

＋

Multi-file Tabs

Version 8 introduces an in-memory multi-file workspace with tabs and a new-file action.

⚙

Persistent Settings

Editor preferences such as font, tab size, wrapping, minimap and line numbers can be stored locally.

↓

Copy & Download

Source can be copied to the clipboard or exported through the browser's Blob/download APIs.

05 · Evolution

From v1 to the Ultimate Workspace

The version folders tell the story of how the project grew feature by feature.

1–3
Foundation

Single-page Monaco editor, AMD loading, custom dark theme, sample source, clipboard copy and Blob download.

4–5
Modular

Core editor setup, features and sample code were separated into reusable modules.

6
Diagnostics

Babel Standalone was introduced for JavaScript parsing, with line/column errors mapped to Monaco markers and hover tooltips.

7
byExtension

A more organized extension-oriented portal, settings persistence, HTML/JS areas and live HTML statistics.

8
Ultimate

Live split preview, AST Inspector, clickable Error Console, quick presets and VS Code-style multi-file tabs.

07 · Run It

Start the project locally

This is a browser application. A simple static HTTP server is enough for the documented development workflow.

Local server

git clone https://github.com/keshavsoft/monacoEditor.git

cd monacoEditor

python -m http.server 3005

Then open

Main editor:

http://localhost:3005/index.html
